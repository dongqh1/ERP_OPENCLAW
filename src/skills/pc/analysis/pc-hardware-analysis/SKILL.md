# PC 硬件分析

## 适用范围

- 查询模拟硬件目录、硬件详情和新旧状态。
- 比较用户点名的硬件，解释规格差异。
- 查询会影响配置选择的陌生游戏、软件、AI 工作负载或硬件术语。
- 根据明确的图表请求绘制模拟目录中的价格、显存和规格对比。

## 工作流程

1. 只提取完成当前任务所需的字段，不要把用户问题改写成整段搜索词。
2. 使用 `hardware_query` 找到候选；需要某个条目的完整参数时，用 `hardware_detail` 按 ID 查询；对多个候选用 `hardware_compare`。
3. 仅在陌生名称会改变用途分类、性能目标或部件选择时调用 `pc_term_lookup(term=...)`。查询过的术语在当前会话不重复搜索。
4. 用户明确要图表时，先从 `hardware_query` 查询图中每个数据点，再调用 `generate_visualization`。例如 GPU 显存/价格图使用 `chart_type="bar"`，每项为 `{category, value}`，标题注明“本地模拟目录”。
5. 返回数据来源、筛选条件和关键缺失信息；不把目录结果包装成真实商城报价。

## 证据边界

- `hardware_query` 和 `hardware_detail` 的 `dataSource=MOCK` 是唯一商品价格/库存/规格依据。
- `gamingScore`、`performanceTier` 是演示指标，不是某款游戏的 FPS 或训练基准。
- 术语搜索用于解释名称，不证明实时兼容性、当前驱动支持、软件性能或市场行情。
- 如需实时或官方技术结论，仅在用户提出相关问题、且可用搜索结果明确支持时引用来源；否则说明该项目目录没有这项证据。

## 图表输出

- 价格柱状图：横轴为型号（可在标签中含显存容量），纵轴为模拟目录价格（元）。
- 显存柱状图：横轴为型号，纵轴为显存容量（GB）。不同量纲不要混在同一个单轴图中。
- 调用图表工具前读取 `/skills/pc/chart_params.md`；只生成用户要求的图表，不默认批量出图。
- 将图表 URL 以 Markdown 图片形式交给主 Agent，并简述图中数据口径。
